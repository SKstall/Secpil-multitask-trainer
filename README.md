# Secpil-multitask-trainer
Entraîneur psychomoteur SECPIL — gratuit et open source. Suivi de trajectoire, palonnier, réaction F1–F4 et calcul mental à travailler en simultané, comme à l'épreuve de sélection pilote EOPN (armée de l'air). Mode libre pour progresser tâche par tâche, campagne en 12 paliers progressifs, examen fidèle au format officiel. Fait avec Claude Code.
